# Expense Tracker MCP

A simple remote MCP server for tracking and managing personal expenses using the Model Context Protocol (MCP).

## Features

- Add and track expenses
- Manage expense records
- Retrieve expense information
- Interact with expenses through an MCP-compatible AI client

## Tech Stack

- Python
- FastMCP
- MCP

## Purpose

This project is built to learn and explore how MCP can be used to create an AI-accessible expense tracking system.
